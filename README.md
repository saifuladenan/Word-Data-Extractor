<h1 align = 'Center'>Word Data Extractor</h1>
<h6 align = 'Center'>An automated text extraction tool that dynamically generates search anchors to identify, retrieve, and organize relevant information from large volumes of text files into structured Excel spreadsheets.</h6>

<h3>Introduction</h3>
<h5 align = 'Justify'>Word Data Extractor is an automated data extraction tool designed to process large volumes of text files, identify relevant information using dynamically generated search anchors, and extract the results into structured Excel spreadsheets. It reduces the need for manual searching, copying, and organizing of information.</h5>

<h3>Problem Statement</h3>
<h5 align = 'Justify'>
    Processing large text files manually can be time-consuming, repetitive, and prone to human error. Traditional               extraction methods may also depend on predefined keywords, fixed positions, or specific text structures.
  </h5>

<h3>Objective</h3>
<h5 align = 'Justify'>
    To simplify and accelerate the process of extracting relevant information from large text files through dynamic anchor      generation and automated Excel data compilation, minimizing manual effort while improving productivity and consistency.
</h5>
